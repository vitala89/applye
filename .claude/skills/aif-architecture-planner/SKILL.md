# AIF Architecture Planner

Use for module boundaries, durable interfaces, data flow, or migrations.

## Steps

1. Identify the domain and data ownership.
2. Map current boundaries with targeted context.
3. Define the smallest viable interface.
4. Check privacy and security implications.
5. Propose staged changes and tests.

## Output

Return decision, affected modules, migration plan, risks, and verification.
