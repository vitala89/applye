# AIF Code Review

Use before finalizing meaningful code changes or when asked for review.

## Steps

1. Review the diff, not memory.
2. Prioritize bugs, regressions, data loss, and missing tests.
3. Check alignment with Applye architecture and privacy principles.
4. Keep findings concrete with file and line references.
5. Separate required fixes from optional improvements.

## Output

Return findings by severity, test gaps, and a brief summary.
