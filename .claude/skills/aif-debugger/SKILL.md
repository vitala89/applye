# AIF Debugger

Use for bugs, failing checks, or unexpected behavior.

## Steps

1. Reproduce or define the failure.
2. Gather minimal context around the failing path.
3. Form one primary hypothesis.
4. Fix root cause, not symptoms.
5. Add or update regression coverage when practical.
6. Verify the specific failure is gone.

## Output

Return reproduction, cause, fix, verification, and residual risk.
