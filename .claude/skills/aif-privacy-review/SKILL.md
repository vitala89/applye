# AIF Privacy Review

Required for user data, storage, sync, notifications, external job sources, plugins, or MCP.

## Steps

1. Identify personal or career data touched.
2. Check where data is stored, sent, retained, or deleted.
3. Require explicit user intent before external sharing.
4. Prefer local-first and minimum data exposure.
5. Document privacy assumptions and user controls.

## Output

Return privacy risks, required controls, and unresolved questions.
