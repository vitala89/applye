# AIF Security Review

Required for auth, secrets, MCP, shell commands, dependencies, browser automation, or external tools.

## Steps

1. Identify trust boundaries and permissions.
2. Check for secret exposure or credential creation.
3. Prefer explicit allowlists and least privilege.
4. Confirm dependency or tool changes are intentional.
5. Document residual risk and required mitigations.

## Output

Return required fixes, mitigations, and security assumptions.
