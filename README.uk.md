**Applye** - це відкритий десктоп-застосунок із локальним зберіганням даних для пошуку роботи за
допомогою ШІ. Він оцінює вакансії відповідно до вашого профілю, адаптує резюме під кожну позицію,
готує чернетки супровідних листів і фолоу-апів, допомагає підготуватися до співбесід і веде весь
пайплайн - усе на вашій машині. Без хмари, без акаунтів, без телеметрії. Ви підключаєте той ШІ, за
який уже платите, і кожне подання лишається рішенням людини.

Створено насамперед для німецького/європейського ринку, але корисно будь-де.

## Навіщо Applye

**Підсилення, а не автоматизація.** Це перший принцип, і все інше підпорядковується йому.

ШІ допомагає. Рішення - за вами. Applye ніколи не подасть заявку, не надішле й не відправить нічого
від вашого імені. Він оцінює, готує чернетки та пропонує - а тоді повертає керування вам. Кожен
результат ШІ - це пропозиція, яку ви читаєте, редагуєте й приймаєте або відхиляєте. Жоден фоновий
агент не представляє вас рекрутеру потайки.

Чому це важливо:

- Рекрутер чи гаряча наймаюча особа - це людина, і стосунки належать вам, а не боту.
- Масові автоматичні заявки - це шум; сенс у інструменті, що допомагає надсилати _менше, але кращих_.
- Ви лишаєтесь відповідальним за кожне слово, що виходить під вашим іменем.

Якщо якась функція колись вимагатиме віддати цей контроль - вона не потрапить у застосунок.

## Швидкий старт

### Завантаження

**[Завантажити для macOS (Apple Silicon)](https://github.com/vitala89/applye/releases/latest)** - `.dmg`, 15 МБ.

Збірки для Windows, Linux і macOS на Intel створює релізний workflow, вони з'являться тут із
наступною версією за тегом. До того часу - [збірка з вихідного коду](#швидкий-старт), три команди,
працює на всіх трьох платформах.

> Збірка для macOS не підписана сертифікатом Apple Developer, тож перший запуск треба робити правим
> кліком по застосунку та **Відкрити**, а не подвійним кліком. У
> [примітках до релізу](https://github.com/vitala89/applye/releases/latest) пояснено чому й наведено альтернативу одним рядком.

### Збірка з вихідного коду

**Вимоги:** Node 20+, Rust (stable, edition 2021) та
[системні залежності Tauri 2](https://v2.tauri.app/start/prerequisites/) для вашої ОС.

```bash
git clone https://github.com/vitala89/applye.git
cd applye
npm install

npm run desktop:dev      # запустити застосунок Tauri + Angular у режимі розробки
```

Інші корисні скрипти:

```bash
npm run desktop:build    # продакшн-збірка десктоп-застосунку
npm run web:dev          # локальний запуск сайту applye.dev
npm test                 # запуск набору тестів
npm run lint             # лінтинг усіх проєктів
npm run type-check       # перевірка типів усіх проєктів
```

Функції ШІ вимкнено, доки ви не додасте ключ або CLI-міст у **Налаштуваннях**. Застосунок повністю
придатний до використання без них.

## Використання: основний цикл

1. **Вставте** опис вакансії (або дозвольте **Discover** знайти ролі з ваших джерел).
2. **Перевірте** - детермінований прохід легітимності, потім опційне прочитання відповідності від ШІ.
3. **Адаптуйте** - багатопрохідна адаптація резюме, яку ви переглядаєте рядок за рядком, з експортом у PDF.
4. **Подайте** - ви копіюєте, відкриваєте вакансію та подаєте. Applye записує це; він ніколи не клікає за вас.
5. **Відстежуйте** - роль рухається канбаном пайплайну; чернетки фолоу-апів з'являються, коли все затихає.
6. **Готуйтеся** - відстежуйте кожен етап співбесіди на таймлайні й ведіть нотатки за кожною роллю.

## Як це працює

**Локально й приватно.** Ваш профіль, список вакансій, нотатки та згенеровані документи зберігаються
в локальній базі SQLite на вашій машині. Основні сценарії працюють узагалі без мережі. Без акаунтів,
без телеметрії, без хмарної синхронізації. Нічого про ваш пошук не залишає пристрій, доки _ви_ не
запустите виклик ШІ, і навіть тоді надсилається лише мінімум, потрібний для цього одного запиту.
Дружньо до GDPR, бо тут нема чому витекти - немає сервера, що тримає ваші дані.

**Підключіть власний ШІ.** Applye не постачає модель і не перепродає токени. Ви під'єднуєте той ШІ,
за який уже платите:

- **API-ключ** - вкажіть Applye на API провайдера (Anthropic Claude, OpenAI, Google Gemini, DeepSeek) з вашим власним ключем.
- **CLI-міст** - або маршрутизуйте через локальний AI CLI, що у вас уже є (Claude Code, Codex, Gemini CLI).

Так чи інакше, ключі ваші, оплата ваша, і ви можете запускати весь застосунок із вимкненими функціями ШІ.

**Економіка токенів.** ШІ трактується як дефіцитний, платний ресурс - не розкиданий усюди:

- **Усе кешується.** Однакові вхідні дані ніколи не оплачуються двічі (`jd_hash -> scoring`, `input_hash -> output`).
- **Лише опційні виклики.** Ніщо не звертається до моделі, доки ви не попросите.
- **Ощадливі промпти.** Функції звужено до найменшого корисного запиту, тож реальний пошук роботи коштує
  копійки, а не підписку.

**Про легальність джерел.** Applye - це інструмент, який ви наводите на описи вакансій, що **ви** вже
переглядаєте. Він не скрейпить джоб-борди, не обходить логіни й не збирає вакансії масово. Discover
отримує лише публічні API та стрічки, призначені для читання програмами. Поважайте умови використання
будь-якого сайту, яким користуєтесь - застосунок побудований так, щоб тримати вас на правильному боці,
ніколи не автоматизуючи ні збір, ні подання.

## Де шукає Discover

Applye постачається з набором вбудованих джерел, і **усі вони вимкнені за замовчуванням**. Збір
даних - явний вибір користувача: ви вмикаєте ті джерела, що відповідають вашому ринку, і доти не
завантажується нічого. Кожне джерело - публічний API або RSS-стрічка, призначена для машинного
читання, і кожне має в застосунку примітку про правову підставу.

| Джерело                  | Тип | Ринок      | Примітка                                             |
| ------------------------ | --- | ---------- | ---------------------------------------------------- |
| Remotive                 | API | Увесь світ | Віддалені вакансії, публічний API                    |
| We Work Remotely         | RSS | Увесь світ | Публічна RSS-стрічка                                 |
| Himalayas                | API | Увесь світ | Віддалені вакансії, публічний API                    |
| Jobicy                   | RSS | Увесь світ | Публічна RSS-стрічка                                 |
| Arbeitnow                | API | Європа     | Публічний API, багато німецькомовних вакансій        |
| Bundesagentur für Arbeit | API | Німеччина  | Офіційний REST API федерального агентства зайнятості |
| No Fluff Jobs            | API | Польща     | Публічний API, фокус на IT                           |
| DOU.ua                   | RSS | Україна    | Публічна RSS-стрічка                                 |
| Djinni.co                | RSS | Україна    | Публічна RSS-стрічка                                 |
| Habr Career              | RSS | RU-ринок   | Публічна RSS-стрічка                                 |
| TrudVsem (Роструд)       | API | RU-ринок   | Офіційний публічний API                              |

Додатково можна додати **кар'єрні портали компаній**: Greenhouse, Lever, Ashby і Personio. Вкажіть
Applye на портал компанії - її вакансії з'являться у стрічці Discover нарівні з агрегаторами. Також
підтримується будь-яка власна RSS-стрічка.

Чого Applye свідомо **не робить**: не парсить HTML джоб-бордів, не входить нікуди від вашого імені
й не викачує вакансії масово. Якщо в сайту немає машиночитної стрічки, Applye його не читає.

## Структура проєкту

```
applye/
├── apps/
│   ├── desktop/          # десктоп-застосунок Tauri 2
│   │   ├── src/          # фронтенд Angular (dashboard, discover, jobs, pipeline, ...)
│   │   └── src-tauri/    # бекенд на Rust: SQLite, рушій сканування, скоринг, міст до ШІ
│   ├── web/              # applye.dev - лендинг, документація, методологія, зміни
│   └── mobile/           # заготовка для майбутнього застосунку-компаньйона
├── libs/
│   ├── core/             # доменні моделі та інтерфейси
│   ├── data/             # обгортки Tauri invoke та абстракції сервісів
│   ├── ui/               # спільні компоненти Angular і дизайн-токени
│   ├── i18n/             # переклади (en, de, ru, es, fr, uk)
│   └── skills/           # версійований контент промптів/скілів
├── docs/                 # архітектурні, продуктові й дизайнерські документи
└── design-system/        # джерело істини дизайну для кожного екрана
```

## Часті запитання

**Що таке Applye?**
Applye - безкоштовний десктопний застосунок з відкритим кодом для пошуку роботи за допомогою ШІ, що
працює локально. Він оцінює вакансії відносно вашого профілю, адаптує резюме під кожну позицію,
готує супровідні листи й нагадування та веде весь пайплайн на вашій машині. Працює на Windows,
macOS і Linux і ніколи не подає заявки замість вас.

**Applye безкоштовний? Чи потрібен обліковий запис?**
Так, безкоштовний і під ліцензією MIT, обліковий запис не потрібен. Немає реєстрації, немає сервера,
немає підписки: ви завантажуєте застосунок, і він працює. Платити можна лише за ШІ, який ви
підключаєте, і платите ви напряму своєму провайдеру, а не Applye.

**Applye подає заявки замість мене?**
Ні й не буде. Applye оцінює, готує чернетки та пропонує; ви перевіряєте, редагуєте й надсилаєте.
Немає ані автоподачі, ані автонадсилання, ані фонового агента, що спілкується з рекрутерами від
вашого імені. Людина в контурі - перший принцип продукту, а не налаштування.

**Де зберігаються мої дані?**
У локальній базі SQLite на вашій машині, поруч із документами, які створює Applye. Немає хмари,
немає синхронізації, немає телеметрії. Нічого не залишає пристрій, доки ви самі не запустите запит
до ШІ, і тоді провайдеру йде лише мінімум, потрібний для цього одного запиту.

**Яких ШІ-провайдерів підтримує Applye?**
Ви приносите свого: ключ Anthropic Claude чи DeepSeek або міст до локального ШІ-CLI - Claude Code
чи Codex (через нього доступні й моделі OpenAI). Ключі та оплата залишаються вашими. Усі ШІ-функції
вмикаються вручну, і застосунок цілком працездатний із вимкненим ШІ.

**Чи можна користуватися без ШІ або без інтернету?**
Так. Дашборд, канбан пайплайну, трекер, таймлайн співбесід, аналітика та детермінована перевірка
легітимності вакансії працюють офлайн і без токенів. ШІ витрачається лише там, де справді потрібне
судження, і лише за вашим кліком.

**Applye парсить джоб-борди?**
Ні. Discover читає публічні API та RSS-стрічки, опубліковані для машинного читання, плюс кар'єрні
портали компаній (Greenhouse, Lever, Ashby, Personio), які ви додаєте самі. Він не парсить HTML, не
обходить логіни й не викачує вакансії масово. Усі вбудовані джерела вимкнені.

**Applye лише для Німеччини?**
Ні. Він зроблений насамперед під німецький та європейський ринок - є звіт Eigenbemühungen для
Agentur für Arbeit, документи німецькою та врахування Blue Card, - але джерела покривають увесь
світ, Польщу, Україну та RU-ринок, а інтерфейс говорить англійською, німецькою, російською,
іспанською, французькою та українською.

**Які платформи підтримуються?**
Windows, macOS (Apple Silicon та Intel) і Linux. Інсталятори публікуються на
[сторінці релізів](https://github.com/vitala89/applye/releases); збірка з початкового коду описана
в розділі [Швидкий старт](#швидкий-старт).
