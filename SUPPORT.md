# Support

Applye is a small open-source project maintained by one person. This page tells you where a
question belongs so it gets an answer instead of getting lost.

## Where to go

| You have                                  | Go here                                                                                       |
| ----------------------------------------- | --------------------------------------------------------------------------------------------- |
| A usage question ("how do I ...")         | [applye.dev/docs](https://applye.dev/docs), then the [FAQ](README.md#faq)                     |
| Still stuck after the docs                | [Discussions](https://github.com/vitala89/applye/discussions)                                 |
| A bug: something is broken or wrong       | [Bug report](https://github.com/vitala89/applye/issues/new?template=bug_report.yml)           |
| An idea for a feature                     | [Feature request](https://github.com/vitala89/applye/issues/new?template=feature_request.yml) |
| A security vulnerability                  | [SECURITY.md](SECURITY.md) - private reporting only, never a public issue                     |
| A story: Applye helped you land something | [Applye helped](https://github.com/vitala89/applye/issues/new?template=applye-helped.yml)     |
| A change you want to contribute           | [CONTRIBUTING.md](CONTRIBUTING.md)                                                            |

## Before you open an issue

- Check that you are on the latest version: the
  [Releases page](https://github.com/vitala89/applye/releases) lists what is current.
- Search existing [issues](https://github.com/vitala89/applye/issues?q=is%3Aissue) - the same thing
  may already be reported.
- Include your OS and Applye version. Without them a bug report usually cannot be reproduced.

## What to leave out

Applye holds your real job search. When you paste logs, screenshots or exported documents into a
public issue, strip anything you would not want indexed by a search engine: recruiter names and
addresses, your full CV, salary figures, and the contents of your profile. A redacted report is
still a useful report.

## What support does not cover

- Career advice, CV reviews, or opinions on whether you should take an offer.
- Guarantees about AI output. Every generated document is a draft you are responsible for.
- Help with an AI provider's own billing, keys, or rate limits - that is between you and them.

## Response times

There is no SLA. This is maintained alongside a full-time job, in the same spare hours the app was
built in. Security reports are looked at first, then bugs that block normal use, then everything
else.
