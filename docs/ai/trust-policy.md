# Trust Policy

Applye handles sensitive career and personal productivity data. AI agents must use conservative defaults.

## Privacy Review Triggers

- User profiles, resumes, notes, contacts, applications, companies, reminders, documents, or job history.
- Local storage, sync, backup, export, or deletion.
- Notifications.
- External job sources, scraping, imports, plugins, MCP, or AI integrations.

## Trust Rules

- Minimize data exposure.
- Keep user intent explicit for external sharing.
- Separate local data handling from network integrations.
- Do not assume telemetry, sync, or AI processing is acceptable by default.
- Record privacy-impacting assumptions in docs or PR notes.
